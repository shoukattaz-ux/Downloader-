# Store listing (draft — edit before use)

**App name (≤30):** Stashly: Downloader & Files
**Short description (≤80):** Save media you own to your device and keep it organised in one tidy place.

**Full description (≤4000):**
Stashly is a simple, fast download manager and file organiser for media you own or are allowed to save.

DOWNLOAD
• Paste a direct link to a video, audio, image or PDF file and see its real size and format before you save it
• Browse and download items from the Internet Archive with the genuine formats and qualities each item offers
• Live progress, speed and time remaining; pause, resume or cancel any time
• Downloads continue in the background, survive restarts and resume after connection drops
• Wi-Fi-only option and low-storage protection

ORGANISE
• Everything you download is sorted automatically into Videos, Audio, Images and Documents — no duplicate copies
• Create folders, move, copy, rename, share and delete files
• Built-in video, audio and image viewer; open documents with your favourite app
• Search, sort and a clear storage overview

PRIVATE BY DESIGN
• No account, no ads, no trackers
• No broad storage permissions
• HTTPS-only downloads; risky file types (apps, scripts, web pages) are blocked

IMPORTANT
Stashly only downloads content you have the right to save. It does not bypass DRM, sign-in, or any website's download restrictions, and does not support downloading from streaming or social platforms that don't allow it. You are responsible for respecting copyright and the terms of the sites you use.
